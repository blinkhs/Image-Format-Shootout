## Introduction

Images are an important part of the modern internet. They appear on websites, social media, online stores, and many other digital platforms. However, images can take up significant storage space and affect how quickly websites load. Because of this, choosing the right image format is an important part of web development. My project, Image Format Shootout, will compare four common image formats: PNG, JPEG, WebP, and AVIF. I will use the same photograph and save it in each format to compare file size, image quality, and browser support.

This topic matters because image formats affect both website performance and the experience of internet users. Large image files can make websites load slowly, especially for people using mobile devices or slower internet connections. Smaller image files can improve loading speeds and reduce data usage. However, reducing file size can sometimes decrease image quality. This creates an important challenge for developers who want their websites to look good while remaining fast and efficient. Understanding different image formats can help developers make better decisions when building websites and managing digital content.

Each image format has different strengths and weaknesses. PNG uses lossless compression, which preserves image details but can create larger files. JPEG uses lossy compression and became popular because it provides relatively small photographic images and works across nearly all browsers. WebP and AVIF are newer formats designed to improve compression while maintaining good visual quality. Although these newer formats offer advantages, their adoption depends on browser compatibility and existing web technologies.

Another important part of my project is understanding why JPEG remained popular for approximately twenty years despite the development of newer formats. I want to investigate how browser support, established technology, and developer habits influenced its continued use.

The main question this blog will answer is: Which image format provides the best combination of file size, image quality, and browser support, and why did JPEG remain so widely used for so long? By comparing these formats using the same photograph and researching their history, I hope to understand how image technology has evolved and which formats are most useful for modern web development.
